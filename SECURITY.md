# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security reports.

Preferred channel:
- Open a private GitHub Security Advisory: https://github.com/nivalis-studio/n-queue/security/advisories/new

If you cannot use GitHub advisories:
- Open a GitHub issue with the minimum details needed to reproduce and clearly mark it as security-sensitive.

## Supported Versions

We support security fixes for the latest published version on npm.

## Disclosure Process

- We will acknowledge receipt and start triage.
- We will work on a fix and coordinate a release.
- We will credit reporters if desired.
